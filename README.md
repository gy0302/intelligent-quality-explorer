# 智能质量的实践探索 

## 项目简述

### 项目起源
作为一名**拥有10年+测试、质量、效能经验**的专业人士，曾负责**测试全流程、DevOps平台构建、质量体系建设、质量管理改进**等工作，现计划基于对研发全流程的痛点有深刻理解，结合现代AI技术，探索并逐步构建智能质量平台。      
本项目不仅是一个技术的实现，更是对**下一代智能质量效能体系**的持续探索与沉淀。

### 项目定位
本项目将以[行业实践痛点](./docs/table/pain-point-problem.md)出发，结合**智能化技术、质量体系规范、其他技术（DevOps技术、云技术等）**，以**接口自动化测试**流程中**自动生成测试用例**的场景为起点，开始探索研发过程中质量与效能双重提高。同时对探索成功的成果进行沉淀，以便形成可复用的能力供后续应用。   
初步规划的探索点如下（后续将持续迭代规划）：   
- **接口测试**：
  - **自动生成&维护接口用例**：流程包含，自动生成测试点->测试用例->测试数据->测试脚本等
  - **智能质量评审**：检查接口测试生成用例的每个环节，使其符合质量体系规范
  - **测试报告分析**：对接口测试的结果、历史趋势等进行分析，并给出建议
- **缺陷分析**：
  - 智能分析缺陷类型、重复检测、缺陷分配等
- **质量知识图谱**：
  - 打通需求、代码、测试用例、缺陷、体系规范的关联，形成知识图谱
  - 支持知识问答等
- ...

## 项目特色
- 以研发痛点问题为基础
- 以质量体系规范为标尺
- 以研发活动为主线细化
- 以智能化、自动化为辅助增强
- 结合度量为质量体系量化展示与决策

项目从范围和方向上是一个较大的工程，目前我个人主要先进行关键技术的探索与场景验证，以便为后续的职业发展、下一代智能化质量体系，沉淀可复用能力。
